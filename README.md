# Customer Churn Prediction — ML vs. LLM

🚧 **Work in progress** — this project is being pushed in stages (data
pipeline → features → modeling → error analysis → LLM comparison), so
some pieces below aren't in the repo yet.

A classical-ML churn classifier on IBM's public Telco Customer Churn
dataset, plus a measured cost/accuracy/latency comparison against an LLM
(zero-shot and few-shot prompting) on the same held-out customers —
answering "do you actually need an LLM for this?" with numbers instead
of an opinion.

Full README with setup instructions, results, and the LLM comparison
write-up is coming as the remaining commits land.
